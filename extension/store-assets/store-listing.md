# SaveIt — 크롬 웹스토어 등록 정보

## 이름
SaveIt

## 짧은 설명 (요약, 132자 이내)
저장한 링크를 잊지 않게. 한 번의 클릭으로 저장하고 PARA로 정리하면, 매일 ‘다시 볼 링크’ 알림과 유튜브 추천으로 다시 만나요.

---

## 자세한 설명

링크는 저장하는 게 끝이 아닙니다. **다시 보는 것**이 진짜입니다.
SaveIt은 저장만 하고 잊어버리던 링크를, 잊지 않고 다시 보게 만들어 주는 북마크 도구예요.

■ 이런 분께 좋아요
• 탭을 수십 개 띄워두고도 결국 안 보게 되는 분
• 나중에 볼 영상·아티클·문서를 자꾸 잃어버리는 분
• 북마크가 너무 많아 정리도, 다시 찾기도 어려운 분

■ 핵심 기능

1. 한 번의 클릭으로 저장
   확장 프로그램 아이콘을 누르거나, 어느 페이지에서나 떠 있는 플로팅 버튼으로
   지금 보고 있는 페이지를 바로 저장해요. 제목·주소는 자동으로 채워집니다.

2. PARA로 자동 정리
   저장한 링크를 Projects(프로젝트) · Areas(영역) · Resources(자료) · Archives(보관)
   체계로 폴더에 정리해요. 전체 보기에서는 카테고리별로 깔끔하게 구분되어 한눈에 들어옵니다.

3. 매일 ‘다시 볼 링크’ 알림
   매일 정한 시간에, 저장해 둔 링크 중 다시 볼 만한 것을 골라 푸시 알림으로 알려줘요.
   하루 1~3회까지 받는 횟수를 직접 고를 수 있어, 잊고 있던 링크를 자연스럽게 다시 만나요.

4. 유튜브 시청 중 저장 영상 추천
   유튜브를 보는 동안, 저장해 둔 다른 영상을 화면 구석에서 살짝 추천해 줘요.
   “나중에 봐야지” 하고 담아둔 영상을 딱 보고 싶은 순간에 다시 꺼내 줍니다.

5. 우선순위 · 빠른 관리
   중요한 링크에는 우선순위를 표시하고, 폴더 이동·수정·삭제도 팝업에서 바로 끝낼 수 있어요.

6. 내 마음대로 끄고 켜기
   설정에서 ‘화면에 상시 표시’와 ‘유튜브 추천 위젯’을 각각 토글로 제어할 수 있어요.
   상시 표시를 끄면 확장 프로그램 아이콘을 눌렀을 때만 열립니다.

7. 어디서나 동기화
   계정으로 로그인하면 저장한 링크와 폴더가 기기 간에 동기화돼요. 회원가입도 확장 프로그램에서 바로 할 수 있습니다.

■ 이렇게 쓰면 좋아요
저장(원클릭) → 정리(PARA 폴더) → 다시 보기(매일 알림 · 유튜브 추천)
이 세 단계만으로, 모아두기만 하던 링크가 실제로 다시 읽고 보는 자료가 됩니다.

지금 SaveIt으로 시작하세요. 저장한 링크, 더는 잊지 않게.

---

## 권한 사용 안내 (심사 참고용)
• storage : 저장한 설정(위젯 표시 여부 등)과 로그인 상태를 기기에 저장하기 위해 사용합니다.
• activeTab : 현재 보고 있는 탭의 제목·주소를 가져와 링크로 저장하기 위해 사용합니다.
• alarms : 정해진 시간에 ‘다시 볼 링크’ 알림을 보내기 위해 사용합니다.
• host 권한(서비스 도메인, Supabase) : 저장 데이터 동기화와 계정 인증을 위해 사용합니다.
저장한 링크 외에 페이지 내용을 수집하거나 외부에 판매하지 않습니다.
